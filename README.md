🎓 Student Performance Predictor | AI Based

**Created by Anushka Ban - B.Tech 1st Year**

### About The Project
This AI project predicts student performance and academic outcome based on various input parameters like study hours, attendance, previous scores, and other factors.

It helps teachers and students to identify at-risk students early and take preventive measures.

### ✨ Features
- 📊 Predicts Student Result / Score / Pass-Fail
- 🧠 Uses Machine Learning Regression / Classification Model
- 📝 Simple Input Form - Enter student details and get prediction
- 📈 Accuracy Tested on Real Dataset
- 💻 Built with Python and Streamlit

### 🛠️ Tech Stack
- **Python** - Core Language
- **Scikit-learn** - ML Model (Random Forest / Linear Regression)
- **Pandas & Numpy** - Data Handling
- **Streamlit** - Web App UI
- **Matplotlib** - Data Visualization

### 🚀 How to Run This Project
1. Clone the repository
2. install dependencies
3. run the application
